# Cân Tất · website giới thiệu

Trang giới thiệu app **Cân Tất** tại https://cantat.vn. Web tĩnh (HTML/CSS/JS).

Folder này nằm trong repo chung `Haonvdes/can-tat`. Push lên `master` có đổi file ở đây thì GitHub Action
tự chép sang repo public `Haonvdes/cantat.vn` và GitHub Pages cập nhật sau khoảng 1 phút.
Không sửa tay repo `cantat.vn`.

Quy tắc khi sửa web (cho người và cho Claude Code): xem `CLAUDE.md` trong folder này.

Tên miền cantat.vn đã trỏ về GitHub Pages (file `CNAME`); không xóa `CNAME` và `.nojekyll`.
